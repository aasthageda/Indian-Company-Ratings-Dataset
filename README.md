# Indian Company Ratings & Reviews Dataset

## Description
This dataset contains information about Indian companies including
ratings, total reviews, industry, main location, salaries reported,
interviews experience, and current job openings.

## Columns
- Company Name
- Rating
- Reviews
- Industry
- Main Location
- Salaries Reported
- Interviews
- Jobs
